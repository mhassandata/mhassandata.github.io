# Muhammad Hassan – Portfolio

Personal portfolio site for Muhammad Hassan — Data Scientist & AI Engineer.

## Local preview

Just open `index.html` in a browser. No build step.

## Customising

- Drop your CV at `assets/pdf/Muhammad_Hassan_CV.pdf` so the **Download CV** button works.
- Add `assets/img/hero.png` and `assets/img/about.png` and re-add the `<img>` elements in `index.html` if you want hero/about visuals back.
- Edit content directly in `index.html`. Styling lives in `assets/css/style.css`.
